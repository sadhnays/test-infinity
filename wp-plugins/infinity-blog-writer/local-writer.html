Write offline and publish instantly to your WordPress blog

Your WordPress API URL

Enter your WordPress site URL + /wp-json/ibw/v1/posts

How to get your API URL

  • Install "Infinity Blog Writer" plugin on your WordPress website.
  • Go to Blog Writer > Settings in your WP dashboard to view the API endpoint.
  • Copy that URL, paste it above, and click Save.
  • You are ready to write and publish from anywhere!
